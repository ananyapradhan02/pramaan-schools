# roadmap

1. **printable one-page outcome report:** a print stylesheet and a `#report` view that turns the mock pilot into the one page a principal takes to the management committee (week 1 → week 8 per section, n answered, what it can and cannot say).
2. **instrument library:** a page per instrument (CEI-II, IMI short form, PALS academic efficacy) with item counts, scales, scoring, age notes, the English and Kannada read-aloud adaptations, and full citations with links.
3. **pilot ops board:** schools → sections → sessions → instruments administered, stored in `localStorage` with CSV export, so Ananya can run the first real pilot from it.
4. **teacher question map for one chapter:** a worked grade 7 science chapter showing the question-first sequence, to make "what a session is" concrete on the offer page.
5. **real pilot inbox and price test:** replace the placeholder mailto and pricing after five principal conversations, and add a one-line outcome promise if testing shows the sixty-second block is not enough.
