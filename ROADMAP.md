# roadmap

1. **instrument library:** a page per instrument (CEI-II, IMI short form, PALS academic efficacy) with item counts, scales, scoring, age notes, the English and Kannada read-aloud adaptations, and full citations with links.
2. **pilot ops board:** schools → sections → sessions → instruments administered, stored in `localStorage` with CSV export, so Ananya can run the first real pilot from it.
3. **teacher question map for one chapter:** a worked grade 7 science chapter showing the question-first sequence, to make "what a session is" concrete on the offer page.
4. **price and promise test:** after five principal conversations, settle the pilot price (raise it if nobody flinches at ₹60,000), and add a one-line outcome promise at the top if testing shows the sixty-second block is not enough. calls stay on the 30-minute calendly link and contact stays on email.
5. **report from real totals:** let the outcome report take a school's own class totals (pasted CSV, kept in the browser) so the first real pilot's page can be printed from it.
